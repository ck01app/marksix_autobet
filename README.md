\# 香港賽馬會六合彩 CSV/Excel 自動投注助手 (HKJC Mark Six Auto-Bet Helper)



🤖 \*\*一個免安裝、完全本地執行的 Chrome 自動化選號與投注擴充功能。\*\*



\### 🔒 為什麼這款工具值得信任？ (Security \& Privacy)

\* \*\*100% 開源透明\*\*：所有代碼公開，絕無任何惡意後門。

\* \*\*純本地執行 (No Remote Server)\*\*：本插件\*\*沒有\*\*配置任何網絡上傳功能。你的 CSV 檔案讀取、號碼解析、網頁模擬點擊，完全在你的電腦瀏覽器本地即時完成，絕不上傳任何帳號、密碼或投注數據。

\* \*\*官方登入環境\*\*：使用者自行在馬會官方網站上安全登入，插件不經手任何登入憑證。



\---



\### 🚀 功能特點

\* \*\*完美對接 Excel\*\*：直接支援從 Excel 複製、以 Tab（製表符）分隔的 6 號碼文字檔（`.txt` / `.csv`）。

\* \*\*自動分批提交\*\*：完全模擬真人操作，每 60 個號碼（10注）自動點擊「添加到投注區 -> 發送 -> 確定」，防止網頁逾時。

\* \*\*滑鼠隨意拖拽\*\*：控制盒支援滑鼠拖拽移動，絕不遮擋網頁投注區域。

\* \*\*隨時手動關閉\*\*：自帶紅色「×」關閉按鈕，隨時還原乾淨的官方網頁。



\---



\### 🛠️ 如何在本地安裝使用？ (Installation)

1\. 下載本項目的所有檔案並解壓到本地資料夾。

2\. 打開 Chrome 瀏覽器，進入 `chrome://extensions/` (擴充功能)。

3\. 在右上方開啟 \*\*「開發者模式 (Developer mode)」\*\*。

4\. 點擊左上角 \*\*「載入未打包擴充功能 (Load unpacked)」\*\*，選取包含本項目的資料夾。

5\. 前往馬會六合彩官方投注頁面，登入帳戶，控制盒將會\*\*自動開啟\*\*！
